05 // Critical Findings — Metasploitable 2
CRITICAL
9.8
CVSS v3.0
Bind Shell Backdoor Detection

An unauthenticated shell was detected listening on a remote port, accepting commands directly as root. No credentials required. Nessus executed id and confirmed full root access remotely.

Plugin: 51988 Port: 1524/tcp (wild_shell) Family: Backdoors
Verify if host is compromised. Reinstall OS if confirmed. Block port 1524 at firewall.
CRITICAL
10.0
CVSS v2.0
VNC Server — Default Password "password"

Nessus successfully authenticated to the VNC service using the password "password". Any unauthenticated remote attacker could gain full desktop control of the system.

Plugin: 61708 Port: 5900/tcp (vnc) Family: Gain a shell remotely
Replace default credentials with a strong, unique password. Consider restricting VNC access by IP.
CRITICAL
9.8
CVSS v3.0
SSL v2 / SSL v3 Protocol Detected

Deprecated SSL 2.0 and 3.0 protocols were active on the host, exposing it to POODLE, BEAST, and man-in-the-middle downgrade attacks. NIST and PCI DSS both prohibit these protocols.

Plugin: 20007 Port: 443/tcp Family: Service detection
Disable SSL 2.0 and 3.0 entirely. Enforce TLS 1.2+ with approved cipher suites.
CRITICAL
10.0
CVSS v3.0
Unsupported OS — Ubuntu 8.04 (End of Life)

Ubuntu 8.04 reached end-of-life over 12 years ago. No security patches are released for this OS version. Every unpatched CVE since 2013 applies. The system is a ticking time bomb.

Plugin: 201352 Port: 80/tcp (www) Family: General
Migrate to a currently supported Ubuntu LTS release (22.04 or later). Do not connect EOL systems to any network.

07 // Conclusion

This lab validated the core principle behind vulnerability management: configuration and patch posture matter more than network position. The Windows 11 host — modern, patched, and defaults-hardened — produced zero critical or high findings despite being scanned without authentication. Metasploitable 2, by design, represented a worst-case real-world scenario: a legacy OS, default credentials, active backdoors, and deprecated cryptography stacked together into a target that would be compromised within minutes in a real environment.

🔄 Patch early and continuously
🔑 Eliminate default credentials
📡 Enforce modern TLS only
🔍 Scan regularly with Nessus
⚰️ Retire EOL systems immediately
